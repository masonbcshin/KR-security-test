## 4. 09:10 실거래 검증

**실제 09:10 체결가 검증은 미완료:** 연구 런은 Yahoo next-OPEN/next-CLOSE 근사만 사용했다. 이 시점의 **인증된 KIS 09:10 체결·호가·잔량·관측날짜/시간·실제 주문 체결내역이 연구 환경에 없어 어떤 후보도 REAL_GATE를 통과시키지 않았다.**

준비한 로컬 **GET-only** 현장 수집 도구: `quote_read_only/collect_kis_0910.py` (PR #31). 단순 quote 스냅샷은 실제 매수 체결을 증명하지 못하며 KIS REST 호가 응답의 시간 필드에 제공자 관측날짜가 없어 시각 신선도와 원시 세션 일자 대사는 별도 필요. 로컬 스냅샷은 외부 GitHub에 커밋하지 말 것.

KIS 주문호가 안전검증은 기존 REAL 코드를 변경하지 않는다. 동일 250 거래일 KIS 일봉과 연구 결측일 **2024-10-30** 독립 종가 증거도 없으므로 **SIGNAL_PARITY=UNVERIFIED**. Yahoo 069500/449180/360750 일부 해당일 데이터 결측을 투명하게 제외했고 미래 데이터로 보간하지 않았다.
